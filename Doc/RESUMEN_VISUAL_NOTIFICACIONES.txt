## 🎯 Resumen Rápido

**El problema**: Las notificaciones reaparecían al recargar la página aunque las marcaras como leídas.

**La causa**: La API retornaba TODAS las notificaciones, no solo las no leídas.

**La solución**: 
1. Backend ahora filtra por estado (leído/no leído)
2. Frontend solicita solo notificaciones no leídas
3. Se recarga automáticamente después de marcar como leído
4. Botón "Ver más" es permanente

**Resultado**: Las notificaciones se comportan correctamente y no reaparecen al recargar.
